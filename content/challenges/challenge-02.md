# Reto 2: Refactorizar código mal diseñado

## Enunciado
Toma una pieza de código tuya de una semana anterior (o código de ejemplo deliberadamente mal estructurado: lógica de negocio, acceso a datos y presentación mezclados en una sola clase o función) y refactorízala sin cambiar su comportamiento observable.

## Objetivo
Demostrar que puedes mejorar la estructura interna de un sistema sin romper lo que ya funciona — la habilidad central del trabajo real con código heredado.

## Puntuación
+40 XP si al final existen pruebas que pasan tanto antes como después del refactor, demostrando que el comportamiento no cambió.

## Penalización
-10 XP si el refactor cambia el comportamiento observable del sistema (aunque el código quede "más limpio").
