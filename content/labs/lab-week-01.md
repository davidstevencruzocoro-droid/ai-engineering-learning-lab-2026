# Laboratorio 1: Crear proyecto profesional

## Objetivo
Preparar una base profesional de trabajo con documentación, estructura clara y evidencia reproducible.

## Resultado esperado
- repositorio con README útil,
- estructura organizada,
- historial de commits visible,
- instrucciones para ejecutar el proyecto.

## Instrucciones
1. Crear una estructura mínima con README, carpetas de código y documentación.
2. Añadir una descripción clara del problema, contexto y pasos de ejecución.
3. Registrar el primer commit con un mensaje significativo.
4. Comprobar la ejecución del proyecto y documentar el resultado.

## Pista
Busca un flujo que un compañero pueda repetir sin depender de tu memoria.

## Pista 2
Separa el README en objetivo, requisitos, instalación, ejecución y verificación; incluye comandos concretos en lugar de asumir que quien lee conoce el entorno.

## Pista 3
Prueba las instrucciones desde una copia limpia del repositorio. Registra la salida de ejecución y corrige cada paso que dependa de archivos o configuraciones no documentados.

## Solución
Documenta un README con:
- objetivo,
- requisitos,
- estructura,
- comandos de ejecución,
- evidencias de verificación.

## Penalización XP
Si no dejas evidencia clara, se resta 10 XP al completar la tarea.

## Criterio de aprobación
Requiere documentación, estructura organizada y verificación mínima del proyecto.
