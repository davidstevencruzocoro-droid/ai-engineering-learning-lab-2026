# Paquete de incorporación — Mentor de Ingeniería de Sistemas con IA

Este paquete está diseñado para usarse con Claude Code desde el directorio donde se realizará la mentoría. El archivo `CLAUDE.md` contiene las instrucciones principales para el agente. Los documentos restantes definen el diagnóstico, la evaluación, los comandos seguros, el primer laboratorio, el plan de cuatro semanas y la plantilla de sesión.

## Incorporación recomendada
1. Revisa el contenido de este paquete antes de copiarlo a un proyecto.
2. Si quieres que Claude Code aplique estas instrucciones a un repositorio, copia `CLAUDE.md` a la raíz de ese repositorio solo después de revisar las instrucciones existentes y los cambios locales.
3. Conserva los documentos de apoyo en una carpeta `docs/mentor/` o en un directorio de estudio aislado.
4. Inicia Claude Code y solicita: `Lee CLAUDE.md y 01_DIAGNOSTICO_INICIAL.md. Inicia el diagnóstico estrictamente de solo lectura. No edites archivos ni instales nada.`
5. Revisa el informe del diagnóstico y aprueba o rechaza por separado las acciones propuestas.

## Importante
- No reemplaces un `CLAUDE.md` existente sin revisar su contenido. Integra las instrucciones cuidadosamente.
- Las instrucciones son una política de trabajo para el agente, no una garantía técnica de que la herramienta siempre obedecerá. Revisa comandos y diffs antes de permitir cambios.
- Nunca pegues secretos, tokens o claves privadas en el contexto del agente.
