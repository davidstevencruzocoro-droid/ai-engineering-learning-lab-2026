# Lab Rules

## 1. Regla de aprendizaje activo

Cada ejercicio debe resolverse con un ciclo claro:

1. entender el problema,
2. construir una solución,
3. probarla,
4. romperla conscientemente,
5. diagnosticar,
6. corregir,
7. documentar.

## 2. Regla de seguridad

No se ejecutarán pruebas ofensivas contra sistemas ajenos sin autorización explícita.

## 3. Regla de evidencia

Todo laboratorio debe dejar evidencia verificable:

- comandos ejecutados,
- resultados,
- capturas o notas,
- diagnóstico,
- corrección,
- resultado final.

## 4. Regla de límites

Un agente no debe recibir permisos ilimitados. Debe tener:

- alcance definido,
- herramientas limitadas,
- validación de entradas y salidas,
- audit logs,
- timeouts,
- presupuestos de ejecución.

## 5. Regla de no dependencia

El estudiante debe aprender sin IA en una parte del ejercicio. La IA sirve como mentor, no como sustituto de la comprensión.

## 6. Ayuda progresiva y recompensa

Cada laboratorio ofrece tres pistas graduadas y una solución final. La recompensa de XP se calcula sobre la XP base del laboratorio:

| Ayuda máxima revelada | XP conservado |
|---|---:|
| Ninguna | 100% |
| Pista 1 | 90% |
| Pista 2 | 75% |
| Pista 3 | 60% |
| Solución | 40% |

Las etapas se revelan en orden. Se conserva la etapa más alta consultada y volver a abrir una ayuda ya vista no añade otra penalización. Si se consulta más ayuda después de completar el laboratorio, el XP de ese laboratorio se recalcula; al desmarcarlo, se resta la recompensa ya ajustada. Los valores fraccionarios se redondean al entero más cercano.

La regla de XP por ayuda sí se aplica automáticamente. El texto “Nota de evaluación” de cada laboratorio es una rúbrica informativa y no se descuenta automáticamente; la app no evalúa la calidad de la evidencia.
